# Tender Hearts International — school website demo

## Run
Open `index.html` in a modern browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `data.js`, `script.js`.
3. Open Settings → Pages.
4. Choose Deploy from a branch, `main`, and `/(root)`, then Save.

## Chatbot
The chatbot is rule-based and works offline. It answers the supplied school FAQs, selected India general knowledge and basic science questions. It displays answers with a character-by-character typing effect and reads them aloud using the browser Speech Synthesis API. The speaker button toggles voice. It prefers an English (India) voice if available.

## Important
The chatbot is not an unrestricted AI assistant or live search. Confirm details before publishing. The fee frequency was not supplied, so the bot gives the amount only and asks users to confirm payment frequency. Family relationships of staff and a staff member's child's name were not added to public FAQs because they are unnecessary personal details. Do not publish student records or private contact information.
